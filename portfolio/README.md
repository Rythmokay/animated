# Animated Canvas Scroll Portfolio

A high-performance Next.js 16 application featuring a smooth 300-frame HTML5 canvas scroll animation, built with React 19, TypeScript, and Tailwind CSS.

## Features

- **300-Frame Canvas Animation**: Ultra-smooth frame-by-frame HTML5 canvas rendering driven by scroll position.
- **Preloaded Frame Pipeline**: High efficiency image preloading and responsive aspect-ratio fitting.
- **Modern UI Components**: Next.js App Router, Tailwind CSS, Lucide icons, and TypeScript.
- **SEO & Performance Optimized**: Structured data, meta tags, static page generation, and optimized canvas frame updates via `requestAnimationFrame`.

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm, yarn, or pnpm

### Installation & Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the interactive scroll animation.

### Production Build

```bash
npm run build
npm run start
```
