# Rythm Video Zip & Scroll Animation Suite

This repository contains the complete interactive scroll canvas animation projects and frame sequence assets for [Rythmokay](https://github.com/Rythmokay).

## Repository Overview

- **`portfolio/`**: Full Next.js 16 + Tailwind CSS portfolio app featuring 300-frame interactive HTML5 canvas scroll animation.
- **`scroll-animation/`**: Next.js 16 canvas scroll animation project component suite.
- **`animated-portfolio/`**: Original 300-frame image sequence (`ezgif-frame-*.jpg`).

## Getting Started

### Portfolio App

```bash
cd portfolio
npm install
npm run dev
```

Visit `http://localhost:3000` to preview the interactive canvas animation on scroll.

### Building for Production

```bash
cd portfolio
npm run build
npm run start
```
